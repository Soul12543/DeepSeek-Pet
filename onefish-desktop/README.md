# 吃白饭的大肥鱼 · 独立桌面软件

双击 `../dist/吃白饭的大肥鱼.app` 即可运行。运行程序、110 段透明动画和宠物引擎全部内置，不需要 DSH、Node 或 npm。本地功能离线可用，朋友联机使用公网服务器。DSH 只是三个可选状态来源之一。

- 同时显示 Codex、Claude Code Desktop、DSH 的状态和任务摘要；点击行打开对应应用。状态面板和右键菜单均使用从本机安装包提取的对应应用原始图标，图标已内置，离线或应用未打开时也能显示。
- 鱼在桌面最顶层显示，支持桌面空间和全屏窗口。任务进行中有气泡显示助手来源与摘要，多个助手同时工作会一并显示；完成提示约 10 秒后恢复当前任务气泡。
- 右键鱼可打开“德州扑克”和“塔罗牌”的独立小游戏窗口。小游戏按普通窗口层级显示，可以被其他窗口遮挡，只留在当前桌面；德州复用原牌局引擎，使用五个本地策略对手和虚拟筹码；另有“朋友联机”模式，Mac 与 Windows 可通过同一房间码同桌。房主可以开局前选择添加、移除机器人补位，真人和机器人合计最多十二席。对手每次行动等待约 0.5 秒，显示当前最佳五张牌与最近升级牌型的具体补牌；先选补牌最少的更高牌型，同样距离时选最大的牌型，且不超过剩余公共牌数。摊牌结果显示获胜牌型及最佳五张牌，分开显示主池、边池和平分；无人跟注时显示弃牌获胜。塔罗保留 78 张牌、四种牌阵、正逆位、两套卡面与独立历史，可复制实际牌面给任意助手解读。两者都不依赖 DSH 启动。
- 点击、右键和拖动以人物实际显示区域判断，靠近顶部、改变大小及自动移动时仍可操作；透明空白继续穿透。拖动鱼可移动；右键打开独立菜单，可点播表情、拖动滑块调大小、固定位置、收起或显示状态面板。菜单按所在屏幕工作区摆放，不受鱼的窗口大小限制。
- 右键菜单直接显示大小滑块；面板齿轮也可调整。界面只显示“小 / 大”，不显示像素数或比例档位。文字面板不随鱼缩小。
- 状态面板在启动或手动打开后显示约 8 秒，然后自动收起。鼠标停留、拖动滑块和键盘操作会延长显示；右键鱼选择“显示状态面板”或点击菜单栏鱼图标可重新打开。状态刷新不会反复弹出面板。
- 键盘灯效：任一助手思考、工作或整理时呼吸；任一任务完成时最高亮度闪两次，其他任务仍在工作则继续呼吸。右键鱼可关闭“键盘灯效”。空闲、锁屏、休眠或退出时恢复接管前亮度，保留自动调光设置，并释放系统控制。仅支持能被本机检测到的 Mac 内置背光键盘。
- Cmd/Ctrl + 滚轮也可缩放。菜单栏里的鱼可重新打开面板或退出。
- 配置独立保存在 `~/Library/Application Support/OneFish/settings.json`，不写入 DSH 配置。

## 状态来源与范围

三者分别保留状态，等待确认、工作、思考、整理和错误仍有各自的表情。一个应用完成任务，不会覆盖另一个应用仍在工作的状态。

待机和工作期间，鱼会在当前状态表情之外，随机穿插移动、小动作、玩耍、吃什么、文字、余额反馈和碎碎念。每段播完再选下一段，并避免紧接着重复同一段。启用“固定位置”时移动动画在原地播放，关闭后使用新增的左、右、上、下四向行走动画在桌面漫游，遇到边缘选择仍有空间的方向，避免连续同方向移动。打开固定位置立即停止移动，动作仍能原地播放。

检测到任一会话的新完成事件，就随机播放一段“吃什么”；其他会话仍在工作时也会触发。多个完成事件依次排队，吃完后继续当前状态的随机播放；拖动和手动点播结束后再处理排队。启动时不会把历史完成任务重播，同一完成事件只响应一次。余额反馈和碎碎念是动画，不会查询账户或调用模型。

Claude Code Desktop：只读 ~/.claude/sessions 中当前仍存活的桌面进程会话，使用原生 busy/idle 状态和任务名称。
Codex：只读 ~/.codex/sessions 的任务事件、工具事件和完成事件，任务名来自 session_index.jsonl。排除子代理。长时间没有新事件的未完成记录显示“状态未更新”。
DSH：只读 ~/.dsh/storages/session_projcache/sessions 中的会话缓存，读取回合、工具和提问状态。依赖 DSH 写入缓存，不调用受桌面鉴权限制的 HTTP 接口。

当前本地状态格式属于应用内部接口，升级后可能变化；不识别的状态显示“状态未更新”。应用关闭显示“未打开”。状态监测不读取凭证、不自动发送会话内容、不调用模型；可选德州 API 机器人仅在你配置并添加后调用指定接口。本版不嵌入三者完整界面，也不通过鱼发送任务。

## 开发与打包

`node --test test/*.test.cjs`
`python3 scripts/build_macos.py --electron /path/to/Electron.app`

键盘控制参考 MIT 开源项目 Dim Keys 的 CoreBrightness 接口，系统私有接口可能随 macOS 升级而变化；探测失败时显示不可用，宠物仍可正常运行。灯效不需要管理员权限。日常动画按素材原速播放，速度为 1×；仅显式运行 --smoke 的验收脚本临时加速。

构建时需要 Electron SDK 和 macOS 命令行编译工具；完成的 app 内含 SDK 副本，运行时没有任何指向 ~/.dsh 或本工程源码的符号链接。安装新 SDK 后可指定任意路径重新打包。

## 四方向新增素材

四套动作来自内置 imagegen，参考原角色正面与侧面帧，每个方向生成一张 4×2 的八帧透明动作表，共 32 张动作帧。`assets/generated-movement` 保留原始动作表、四套 GIF、切分帧、逐方向提示词及校验记录；运行时使用保持透明背景的 WebM，沿用现有播放器。生成记录见 generation.json，组装记录见 assembled.json。

重新组装需要 Pillow 和 ffmpeg，运行 scripts/assemble_movement.py。所有新素材已内置应用。


## 与朋友联机 · 0.6.1

Mac 版和 Windows 64 位便携版在 `dist/releases`。Windows 需要把 ZIP 整体解压后运行“吃白饭的大肥鱼.exe”，运行环境和全部素材均已内置；Mac 版分别支持 Apple Silicon 和 Intel，使用本地签名，分发到其他 Mac 时可能需要通过系统的“仍要打开”确认。当前没有商业发行签名证书。

右键鱼 → 德州扑克 → 朋友联机。服务器地址默认为空。填写自己的 HTTPS 牌桌地址和昵称即可创建房间，朋友也可粘贴完整邀请链接自动带入地址。房主可选原来的五名机器人，添加、移除后开局。断线自动恢复原座位；多人真人每次行动 20 秒，到时可过牌就过牌，否则弃牌。请通过“离开房间”退出，房主身份交给下一位在线朋友。

牌桌、发牌和筹码结算在服务器，其他人的实时底牌不会发给自己的软件；加注和行动次序由服务器检查。牌型提示与获胜牌型沿用本地版。联机窗口仍是普通窗口，动画保持原速。服务器重启会结束现有房间；全部离线 30 分钟后房间过期。房间凭证与昵称保存在自己的软件设置目录 `games/online-poker.json`，不会复制到邀请信息。

Windows 的游戏、宠物和状态读取使用跨平台路径，进程检测使用 tasklist。键盘背光仅支持已有 Mac 内置键盘接口，Windows 中显示不可用。Windows 的安装包结构已检查，未在真实 Windows 主机进行桌面验收。


## 十二席与轮流出牌 · 0.6.1

朋友联机最多十二席，真人和机器人合计。同一种机器人可重复添加，复制实例各自持有独立座位、筹码和底牌，并使用原机器人头像。机器人默认每次等待 0.5 秒；多人真人每次有 20 秒，能过牌则自动过牌，否则自动弃牌，不会自动跟注。断线重连不延长当前行动时间，逾时操作也不能抢先被接受。本地练习没有真人限时。

下注按钮和倒计时固定在窗口底部，十二席列表可滚动；宽窗口采用四列，窄窗口自动改为三列或两列。服务器规则由公开状态同步，客户端界面遵守该规则。服务器部署更新会结束旧房间，需要重新建房。


单人不限时：本地练习，以及房间仅有一位未离席真人、其余为机器人时，不设置真人出牌截止时间。另一位真人只是断线而没有离席，仍按多人规则计时，重连不延长当前回合。房间最后一位其他真人离开时，当前真人的旧计时会被取消。机器人仍默认 0.5 秒行动。


## 0.10.0 私人练习与 API AI

隐蔽 astra 按键、旧 IPC 与旧服务器 `astra` 命令继续禁用。可见的「astra · 单人练习」菜单只在离线版或恰好一位真人且有机器人的私人房间开放。设置只作用于下一手，给该真人最终最佳牌型；通常以同类牌型更高的点数胜出，大牌低概率出现。该设置不保证玩家不会弃牌或提前输掉底池。第二位真人（含待确认申请和未离桌的断线玩家）会禁止练习并取消未生效设置，发牌前再次检查。多真人对局仍正常随机发牌。

### 配置 API 机器人

德州扑克 →「AI 机器人 · API 设置」填写昵称、接口格式、API 地址、模型名称和密钥，保存后点「添加到当前牌桌」。本地或联机均在开局前添加、移除；重新开桌后再调整。可保存多个配置，同一配置可添加多个机器人；真人与机器人合计最多 12 席。原来的规则机器人继续可用。

- OpenAI 兼容：地址支持 `https://服务商/v1` 或完整 `/chat/completions` 路径。
- Anthropic Messages：地址支持 `https://服务商/v1` 或完整 `/messages` 路径；使用 `x-api-key`、`anthropic-version: 2023-06-01`，system 放在请求顶层。
- 模型名由你填写，支持第三方兼容网关，不依赖 DSH。离线可用 localhost HTTP 的本地模型；联机要求公网 HTTPS，并拒绝内网、元数据地址和重定向。
- 每次只向模型发送该机器人自己的底牌、公共牌、公共下注和最近行动。不会发送你的其他软件任务、API 密钥或对手底牌。动作由原规则引擎校验；不合法、超时或连接失败回退规则人机，取消/重新开桌不会提交旧回复。
- 规则机器人仍默认 0.5 秒；API 机器人等待接口响应，显示思考状态。最长等待可设 5–60 秒，默认 15 秒。API 服务可能计费，由配置该机器人并添加的人承担。
- API 密钥保存在用户数据目录的 `games/ai-profiles.json`（权限 0600），界面只返回是否已配置；分享链接、日志和安装包不含密钥。联机设置由该房间当前房主经 HTTPS/WSS 发送，服务器只保存在该房间内存中；移除机器人或关闭房间后清除，不向朋友广播。不要把用户数据目录一起打包分享。

实现复用 [dsh-holdem](https://github.com/bubbleptr/dsh-holdem) 的 AI 提示、合法动作、取消机制和结算引擎，协议依据 [Anthropic Messages 文档](https://platform.claude.com/docs/en/api/messages/create) 与 [DeepSeek Chat Completion 文档](https://api-docs.deepseek.com/api/create-chat-completion/)。

## 0.10.1 界面稳定与房主审核

机器人选择框只在选项真正变化时更新；选择框聚焦时延后更新，避免关闭原生下拉菜单。机器人、API 配置和入桌审核列表保留节点；没有状态变化时不重复发送完整界面状态，时钟单独更新。连续添加角色不会不断替换选择控件。

所有人都可以在自己配置的服务器创建房间；入桌仍由当前房主批准。联机 API 机器人也只需当前房主身份，不需要特殊设备证书。软件首次运行的牌桌地址为空，更新已有安装时保留用户自己保存的地址，完整邀请链接可以带入对应服务器。
